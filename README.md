# 國小一年級注音田字格練習卷產生器 (ㄅㄆㄇ練習卷產生器)

一個專為國小一年級學生與教師設計的客製化注音與國字田字格練習卷產生器。支援動態自動轉注音、描紅練習格設定、破音字聲調微調與 A4 尺寸無邊框直印/輸出 PDF。

## ✨ 核心特色

- **中文與注音自動轉換**：輸入中文會自動解析發音與聲調，亦支援直接輸入注音符號（如 `ㄇ一 ㄒ一ㄠˇ`）。
- **多種版面模式**：
  - **純注音田字格 (大)**：9×12 大格練習卷。
  - **國字注音格**：7×12 練習格，支援切換顯示或隱藏國字（製作純注音本）。
- **豐富練習選項**：
  - 單字整欄練習 (一字一欄) / 全文連續填滿 (格子流)。
  - 直排與橫排書寫方向。
  - 描紅格數設定 (0~11 格灰字描紅練習)。
  - 田字格 / 米字格切換，以及課本綠、粉紅、綠、藍、灰等多種顏色主題。
- **互動微調**：點擊預覽區文字可彈出對話框調整破音字發音與聲調。
- **A4 列印優化**：一鍵列印或輸出為 PDF 格式。

## 🏫 設計說明

本專案由中正國小 115 學年一年級導師共同設計。
